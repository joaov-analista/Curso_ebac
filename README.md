Este repositorio contém alguns programas que criei desde que comecei a aprender programação


Como executar o arquivo .SH
abra seu Ubuntu
procure o caminho para o arquivo
digite o comando ./calculadora.sh
a calculadora funciona de forma bem intuitiva
terá um menu com as opções de calculos que deseja
digite a opção de deseja e em seguida digite os numeros que deseja calcular
o resultado aparecerá em seguida

o arquivo par_ou_impar.py é um programa do famoso jogo de par ou impar e é muito simples de executar
digite a opção que deseja (par ou impar) 
digite um numero de 1 a 5 que voce deseja jogar
ira aparecer o resultado do jogo, o numero que o programa jogou e o numero que voce jogou

o arquivo cinema.py também é bem simples, detecta se um filme pode ser assistido de acordo com a idade
